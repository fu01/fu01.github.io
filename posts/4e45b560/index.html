动词

普通形 包含 原型（辞书形）、ない形、た形、なかった形

变态动词

动词变形后词性会发生变化

  1. 可能态（能……）
  2. 被动态（被……）
  3. 使役态（让/叫……去做）
  4. 使役被动态（被迫/不得不做……）
  • 一类动词（五段） → 变成二类（一段）
  • 二类动词（一段） → 变完依然是二类（一段）
  • 三类动词（不规则） → 变完全变成了二类（一段）

区分动词

  1. 一类动词：词尾为う段，倒数第二是【あ、う、お】段。

  2. 二类动词：句尾为る，倒数第二是【い、え】段。

  3. 三类动词：する、くる、名词接する

自动词和他动词

自动词

描述事物本身的变化或状态，不强调谁去做的。

助词：が

例： ドアが開く (门开了) —— 关注点在“门”本身的状态。

他动词

强调“某人做了什么”从而导致了结果，必须有施动者。

助词：を

例： 私がドアを開ける (我把门打开了) —— 关注点在“我”的操作。

常见区分方法

第一类：-aru / -eru 对应规律（最常见）

自动词以 -aru 结尾 他动词以 -eru 结尾
閉まる (shimaru) 閉める (shimeru)
止まる (tomaru) 止める (tomeru)
壊れる (kowareru) 壊す (kowasu)

第二类：-eru / -asu 对应规律

自动词以 -eru 结尾 他动词以 -asu 结尾
出掛ける (dekakeru) 出す (dasu)
沸く (waku) 沸かす (wakasu)

ます

  1. 一类动词 词尾う段变い段 接ます
  2. 二类动词 去除词尾る 接ます
  3. 三类动词 する 变 します，くる 变 きます

ます 过去时ました 否定ません　过去否定ませんでした

て形

一类动词

  1. 词尾[う、つ、る]变っ 接て
  2. 词尾[む、ぬ、ぶ]变ん 接で
  3. 词尾く变い 接て
  4. 词尾ぐ变い 接で
  5. 词尾す变し 接て

二类动词

  1. 去掉词尾る 接て

三类动词

  1. する -> して
  2. くる -> きて

た形同て形一样

ない形

  1. 一类动词 词尾う段变あ段 接ない （词尾是う变わ，ある->ない）
  2. 二类动词 去掉词尾る 接ない
  3. 三类动词 する->しない　くる->こない

ない 过去否定 なかった

意志形 (意向形)

用途： 表示“……吧”（提议）或“打算做某事”。

  1. 一类： 词尾 u 段 –> o 段 + う（例：行く –> 行こう）
  2. 二类： 去 る + よう（例：食べる –> 食べよう）
  3. 三类： する –> しよう；来る –> こよう

可能形 (能力形)

用途： 表示“能、会、可以”。

  1. 一类： 词尾 u 段 –> e 段 + る（例：行く –> 行ける）
  2. 二类： 去 る + られる（例：食べる –> 食べられる）
  3. 三类： する –> できる；来る –> こられる

假定形 (条件形)

用途： 表示“如果……的话”。

  1. 一类： 词尾 u 段 –> e 段 + ば（例：行く –> 行けば）
  2. 二类： 去 る + れば（例：食べる –> 食べれば）
  3. 三类： する –> すれば；来る –> くれば

命令形

用途： 语气强烈的命令或号召。

  1. 一类： 词尾 u 段 –> e 段（例：行く –> 行け！）
  2. 二类： 去 る + ろ / よ（例：食べる –> 食べろ！）
  3. 三类： する –> しろ/せよ；来る –> こい

被动形 (受身形)

用途： 表示“被……”，或者表达对他人的尊敬（高级语法）。

  1. 一类： 词尾 u 段 –> a 段 + れる（例：言う –> 言われる）
  2. 二类： 去 る + られる（例：食べる –> 食べられる）
  3. 三类： する –> される；来る –> こられる

使役形

用途： 表示“让、叫、使某人做某事”。

  1. 一类： 词尾 u 段 –> a 段 + せる（例：行く –> 行かせる）
  2. 二类： 去 る + させる（例：食べる –> 食べさせる）
  3. 三类： する –> させる；来る –> こさせる

禁止形

用途： 表示强烈的禁止或警告（语气生硬）。

  1. 一类： 动词原形 + な（例：行く –> 行くな！）
  2. 二类： 动词原形 + な（例：食べる –> 食べるな！）
  3. 三类： する –> するな；来る –> くるな

中止形（连用形）

用途： 用于句中停顿/并列（书面语），或作为词干拼接其他语法（如加 ～たい 表示想做）。

  1. 一类： 词尾 u 段 –> i 段（例：行く –> 行き）
  2. 二类： 去 る（例：食べる –> 食べ）
  3. 三类： する –> し；来る –> き

句中停顿与连接（书面语/新闻）

  1. 在正式书面语、新闻报道或文章中，替代口语中的 て形 来连接前后的动作，使句子更严谨、干练。
  2. 例：毎朝新聞を読み、コーヒーを飲む。（每天早上读报纸，然后喝咖啡。）

作为“积木底座”拼接语法或构词

  1. 接续语法后缀：拼接 ～たい（想……）、～やすい / ～にくい（好/难……）、～ながら（一边……一边……）等。
  2. 组合复合词：与其他动词或名词组合构成新词，如 見 + 直す → 見直す（重新审视）、見 + 物 → 見物（观光）。

连体形

把动词、形容词等原型放在名词前面，做定语修饰名词

  1. 傷付く（受伤） + 合図（信号） → 傷付く合図（受伤的信号）
  2. 忘れる（忘记） + 物（东西） → 忘れる物（遗忘的物品）

使役被动形

把使役（让某人做）和被动（被……）结合在了一起，字面意思是“被要求做某事”，语感上通常表示：“不由自主地……” 或 “被迫/无奈做某事”。

变形方式（最长、最绕）

规则是：先变“使役”，再变“被动”。

  1. 一类动词（五段）： 词尾 u –> a 段 + せられる。
    • 例：書く –> 書かせられる (被要求写)
    • 口语缩略版（最常用）： 词尾 u –> a 段 + される。
    • 例：書く –> 書かされる
    • 注意：词尾是「す」的动词（如：话す）不能缩略。
  2. 二类动词（一段）： * 去 る + させられる。
    • 例：食べる –> 食べさせられる (被逼着吃)
  3. 三类动词（不规则）：
    • する –> させられる (被要求做)
    • 来る –> 来（こ）させられる (被要求来)

用法与语感

这个变形主要表达两种“身不由己”的情况：

  1. 被迫、被命令（他动性）

    • 当你不想做某事，但迫于压力、规则或他人的命令不得不做时。
    • 先生に作文を書かされた。(被老师逼着写了作文。)
    • お母さんに野菜を食べさせられた。(被妈妈强迫吃了蔬菜。)

  2. 不由自主地、自然而然地（自发性）

    • 常用于心理动词。某种情感或想法“被动地”从内心涌现。
    • その映画を見て、感動させられた。(看了那部电影，禁不住被感动了。—— 直译：被电影给感动了)
    • 彼の言葉に考えさせられた。(他的话让我陷入了沉思。—— 直译：被逼着去思考了)

只要你熟练掌握了：使役形 (～せる / ～させる) 被动形 (～れる / ～られる) 就能推导出“使役被动”。但在实际口语中，最常听到的是那个缩略后的 「～される」，容易和普通的“被动形”搞混。

未然形

否定形（ない形）

结构公式： 未然形底座 + ない

  1. 一类动词（五段）： 词尾变 a 段音 + ない
    • 吸い込む → 吸い込まない（吸い込ま 为未然形）
    • 書く → 書かない（書か 为未然形）
    • 買う → 買わない（買わ 为未然形）
  2. 二类动词（一段）： 去掉词尾 る + ない
    • 食べる → 暴吃 / 告べない（食べ 为未然形）
    • 見る → 見ない（見 为未然形）
  3. 三类动词（不规则）： 变音底座 + ない
    • する → しない（し 为未然形）
    • 来（く）る → 来（こ）ない（こ 为未然形）

被动形（受身形）

结构公式： 未然形底座 + れる / られる

  1. 一类动词（五段）： 词尾变 a 段音 + れる
    • 吸い込む → 吸い込まれる（吸い込ま 为未然形）
    • 書く → 書かれる（書か 为未然形）
    • 買う → 買われる（買わ 为未然形）
  2. 二类动词（一段）： 去掉词尾 る + られる
    • 食べる → 告べられる（食べ 为未然形）
    • 見る → 見られる（見 为未然形）
  3. 三类动词（不规则）： 变音底座 + れる / られる
    • する → される（さ 为未然形）
    • 来（く）る → 来（こ）られる（こ 为未然形）

使役形 (未然形)

结构公式： 未然形底座 + せる / させる

  1. 一类动词（五段）： 词尾变 a 段音 + せる
    • 吸い込む → 吸い込ませる（吸い込ま 为未然形）
    • 書く → 書かせる（書か 为未然形）
    • 買う → 買わせる（買わ 为未然形）
  2. 二类动词（一段）： 去掉词尾 る + させる
    • 食べる → 告べさせる（食べ 为未然形）
    • 見る → 見させる（見 为未然形）
  3. 三类动词（不规则）： 变音底座 + せる / させる
    • する → させる（さ 为未然形）
    • 来（く）る → 来（こ）させる（こ 为未然形）

使役被动形（被逼做某事）

结构公式： 未然形底座 + せられる / させられる（一类动词口语常缩略为 される）

  1. 一类动词（五段）： 词尾变 a 段音 + される / せられる
    • 吸い込む → 吸い込まされる（吸い込ま 为未然形）
    • 書く → 書かされる（書か 为未然形）
    • 買う → 買わされる（買わ 为未然形）
  2. 二类动词（一段）： 去掉词尾 る + させられる
    • 食べる → 告べさせられる（食べ 为未然形）
    • 見る → 見させられる（見 为未然形）
  3. 三类动词（不规则）： 变音底座 + させられる
    • する → させられる（さ 为未然形）
    • 来（く）る → 来（こ）させられる（こ 为未然形）

形容词

な形容词

  1. 普通形 な形容词词干+だ　过去时な形容词词干+だった　现在否定な形容词词干+ではない　过去否定な形容词词干+ではなかった

  2. 敬体形 现在时な形容词词干+です 过去时な形容词词干+でした 现在否定な形容词词干+ではありません或ではないです 过去否定な形容词词干+ではありませんでした或ではなかったです

  3. な形容词+な+名词 例如: 大変な仕事

  4. で形(表示并列或中顿) 例如: 静かで

  5. な形容词+に+动词 例如: 静かにして

い形容词

  1. 普通形 [词干+い(词尾)] 过去时 [い(词尾)变かった]　现在否定 [い(词尾)变く 接ない] 过去否定 [い(词尾)变く 接なかった]

  2. 敬体形 现在时 [词干+い+です] 过去时 [词干+かった+です] 现在否定 [词干+く+ないです或ありません] 过去否定 [词干+く+なかったです或ありませんでした]

  3. い形容词+名词 例如: 冷たいコーヒー

  4. て形 (表示同一事物的各种性质，特征等，前后词语属于并列或递进关系) [い(词尾)变く + て] 注: 多形容词对同一个主体进行描述，且属于并列关系，て可以省略

  5. い形容词+动词 [い(词尾)变く 接动词]

其他变形

假定形（如果……的话）

用来表示“如果（天气好/安静）的话”：

  1. い形容词：去 い + ければ（例：高い → 高ければ / 如果贵的话）
  2. な形容词：词干 + なら（ば）或 であれば（例：静か → 静かなら / 如果安静的话）

意志形 / 推测形（大概……吧）

用来表示推测（普通形）：

  1. い形容词：保留 い + だろう（例：高い → 高いだろう / 大概很贵吧）
  2. な形容词：词干 + だろう（例：静か → 静かだろう / 大概很安静吧）

名词化（把形容词变成名词）

把形容词变成名词（用来表示程度、概念或状态）：

  1. い形容词：去 い + さ（例：高い → 高さ / 高度；高く → 高み / 高处）
  2. な形容词：词干 + さ（例：静か → 静かさ / 安静程度/寂静）

补充：容易混淆的另一个名词化后缀 「み」

  1. 「さ」＝ 客观测量、程度、属性（抽象且标准）
    • 例：深さ 10m（深 10 米 —— 客观数据）
  2. 「み」＝ 主观感受、具体的肉体/情感体验（具象且有质感）
    • 例：味わいのある深み（有韵味的深度/深度感 —— 情感体验）

补充特例（避免踩坑）

「いい」的所有变形都必须基于原形「よい（良い）」来变！

  • 否定：良（よ）くない
  • 过去：良（よ）かった
  • 中顿（て形）：良（よ）くて
  • 变副词修饰动词：良（よ）く

助词

格助词

例如: が を に で へ と から/まで より

提示助词 / 副助词

例如: は も だけ/しか でも

接续助词

例如:

  1. て / で（如：食べて寝る）
  2. から / ので
  3. が / けど
  4. と / たら / なら / ば

终助词

例如: か ね よ な/なあ

接续词（连词）

位置特征：必须站在一句话的最开头，后面通常跟着逗号，用来连接上下两个句子。

例如：しかし（但是）、だから（所以）、そして（然后）、それに（而且）

副词

位置特征：游走在动词或形容词的前面，专门用来修饰动作怎么做、或者程度有多深。

例如: とても（非常）、ちょっと（有一点）、全然（完全）、いつも（总是）、たまに（偶尔）、ゆっくり（慢慢地）、しっかり（好好地）

接尾词

核心逻辑：不能单独存在，必须死死贴在名词或动词词干屁股上，把前面的词组合成一个全新的词

名词类

例如：〜者（しゃ） 〜化（か） 〜性（せい） 〜感（かん） 〜制（せい）

形容词类

例如：〜やすい 〜にくい 〜っぽい

数量范围类

例如： 〜等（とう/など） 〜中（ちゅう/じゅう）

敬语尊称类

例如：〜様（さま） / 〜さん / 〜君（くん）

象声词系统（包含拟声词、拟音词、拟态词）

  1. 拟态词
    • 用发音来描绘“没有声音的状态、动作或心理感受”的词
    • 拟态词： 描绘无声的视觉画面、生理感觉或心理状态。
      • 头晕/摇晃： グラ（ぐら）（无声，用来表现一阵眩晕）
      • 微笑： ニコニコ（无声，用来表现笑眯眯的状态）
      • 心跳/紧张： ドキドキ（心理上的紧张感）
  2. 拟声词 / 拟音词： 描绘耳朵能听到的真实声音。
    • 拟声词： 汪汪叫（ワンワン） → 突然汪了一声（ワンッと） → 口语唱法（ワンて / ワンって）
    • 拟音词： 嘭嘭响（バンバン） → 猛地嘭一声（バンッと） → 口语唱法（バンて / バンって）
  3. 语法
    • 核心词根（オノマトペ语根）： 提供最基础的感觉语义（如 グラ 表示不稳、摇晃）。
    • 形态派生规则（词汇构词）：
      • 叠词化（Reduplication）： AB → ABAB（表示动作/状态的持续、重复）。
        • 例：グラ → グラグラ（一直摇晃）
      • 促音化修饰（Gemination + 格助词 と）： AB → AB + っ + と（表示动作/状态的瞬间性、爆发性、一次性）。
        • 例：グラ → グラっと（猛地一晃）
      • 格助词口语化（と → て / って）： 修饰副词的格助词 と，在口语、歌词、漫画等强调感官现场感的语境下，弱化并替换为接续/状态助词 て（或促音化的 って）。
        • 例：グラっと → グラって
    • 公式: 词根 (AB) + 促音 (っ) + 口语助词 (て/と) ⇒ 表瞬间冲击的状态修饰

前缀词

「真（ま）」

与词汇拼接时，是否使用促音 「っ」，本质上取决于后续词汇的发音开头（辅音）以及词性/习惯。

  1. 必须加「っ」（变为「真っ」）

    • 规则：后续词汇以 カ行、サ行、タ行、ハ行 开头，且多用于表示颜色、状态、抽象空间（强调“极度、彻底”）。

      • 颜色类
      • 真っ赤（まっか）：鲜红
      • 真っ白（まっしろ）：雪白
      • 真っ青（まっさお）：湛蓝 / 脸色苍白
      • 真っ黒（まっくろ）：漆黑 / 乌黑

    • 状态 / 抽象空间类

      • 真っ逆さま（まっさかさま）：彻底颠倒 / 头朝下
      • 真っ直ぐ（まっすぐ）：笔直

  2. 不需要加「っ」（保持「真（ま）」）

    • 规则：后续词汇以 元音（ア行） 或 自然方位/时间名词 开头，直接拼接（强调“正中、正值”）。

    • 方位 / 物理位置

      • 真上（まうえ）：正上方
      • 真下（ました）：正下方
      • 真前（ままえ）：正前方
      • 真横（まよこ）：正侧面
      • 真中（まなか）：正中间（注：口语更常用拨音 真ん中 まんなか）

    • 时间 / 季节

      • 真冬（まふゆ）：严冬 / 正冬
      • 真夏（まなつ）：盛夏 / 正夏
      • 真夜中（まよなか）：深夜 / 半夜

语法

〜の/んです

只要不是 纯粹汇报客观信息、做自我介绍、读课文/新闻 都需要用到

  1. 动词普通形/い形容词普通形 + の/んです
  2. な形容词词干 + な + の/んです
  3. 名词 + な + の/んです
  • のだ：语法教科书上的基础形/书面形（口语直接说会显得像动漫角色或写文章）。
  • んだ：日常口语中最自然、最常用的男性/通用简体。
  • の：日常口语中语气最柔和的女性/通用简体。

额外注明何为普通形: $$\text{普通形（统称）} = \begin{cases} \text{辞書形（现在肯定）} & \text{例：食べる} \\ \text{ない形（现在否定）} & \text{例：食べない} \\ \mathbf{た形（过去肯定）} & \mathbf{例：食べた} \\ \text{なかった形（过去否定）} & \text{例：食べなかった} \end{cases}$$

い形容词普通形 同上

例句:

  1. 明日は休みです。
  2. 明日は休みなんです。

区别：前者是向对方做日程汇报（“明天是休假”）；后者是在为“今晚可以熬夜”或“明天不能去公司”作背景解释。

  1. どこへ行きますか。
  2. どこへ行くの？（口语简体）/ どこへ行くんですか。（礼貌语）

区别：前者像警察或门卫查问行程（“目的地是哪里”）；后者是看到对方换好衣服、拎着包准备出门，顺着眼前的异常举动关心提问（“你这是要干嘛去呀”）。

  1. バスが来ませんでした。
  2. バスが来なかったんです。

区别：前者是客观陈述一句废话（“公交车没来”）；后者是迟到进教室/办公室时，向老师或老板解释“我为什么迟到”。

  1. ちょっと頭が痛いです。早退してもいいですか。
  2. ちょっと頭が痛いんですが、早退してもいいですか。

区别：前者是两个孤立句子的硬拼（“头疼。想早退。”）；后者用 んです 把头疼变成请假的前提条件，语气自然顺畅。

のに

用来表示转折（“明明……却……”），带有强烈的出乎意料、遗憾、抱怨或不满的情感。

  1. 动词普通形/い形容词普通形 + のに
  2. な形容词词干 + な + のに
  3. 名词 + な + のに

注意: な + のに 仅适用于“现在肯定”时态，语法の/んです也一样

词性 状态 接 〜んです 接 のに
な形容词 现在肯定 暇なんです ⚠️ 暇なのに ⚠️
现在否定 暇じゃないんです 暇じゃないのに
过去肯定 暇だったんです 暇だったのに
名 词 现在肯定 病気なんです ⚠️ 病気なのに ⚠️
现在否定 病気じゃないんです 病気じゃないのに
过去肯定 病気だったんです 病気だったのに

形式名词「の」和「こと」(名词化)

「の」

特点：口语感强、偏具象、偏眼前的感官动作或具体物品。

动词:

  • 句子：一人で旅をする（一个人去旅行）
  • 名词化：一人で旅をするのは楽しい。（一个人去旅行很开心。）

い形容词:

  • 句子：甘い（甜的）
  • 名词化：甘いのを一つくだい。（请给我一个甜的[那个]。）

な形容词:

  • 句子：静かだ（安静）
  • 名词化：静かなのが好きです。（我喜欢安静的[环境/东西]。）

名词:

  • 句子：私（我）
  • 名词化：この 傘は 私のです。（这把伞是我的[东西]。）

「こと」

特点：正式书面语、偏抽象概念、经验、兴趣或固定语法搭配。

动词:

  • 句子：外国語を 勉強する（学习外语）
  • 名词化：外国語を 勉強することは 重要です。（学习外语这件事很重要。）

い形容词:

  • 句子：高い（贵/高）
  • 名词化：高いことが 必ずしも いいとは 限らない。（“贵”这件事并不一定意味着好。）

な形容词:

  • 句子：安全だ（安全）
  • 名词化：一番 重要なのは 安全なことです。（最重要的是“安全”这件事。）

名词:

  • 句子：将来（将来）
  • 名词化：将来のことを 考える。（思考关于将来的事。）

「って」

口语中极其高频的万能替代工具。它的核心作用是将书面语或正式语法中的 は（主题）、と（引用）、という（定义）等繁琐接续，在口语中统统压扁简化为一个音节。

主题（替代 ～は）

作用：用于提起谈论的人、事、物，语气比 は 更随性自然。

  • 中文直译：说到…… / 提起……
  • 例句：田中さんって 本当に優しいね。（说到田中，人真的很温柔呢。）

传话与引用（替代 ～と / ～と言いました）

作用：引用他人说的话、传达听到的消息或表达内心的想法。

  • 中文直译：听说…… / 说……
  • 例句：明日は 雨が 降るって。（听说明天会下雨。）

解释与定义（替代 ～名词という名词）

作用：用来询问或解释某个不熟悉的名称、概念或定义。

  • 中文直译：所谓的…… / 叫作……的……
  • 例句：「AI」って 何ですか。（所谓的“AI”是什么意思？）

情绪化强调与反驳（句尾语气词）

作用：放在句尾表达生硬、耐烦的强调，或是对对方质疑的反驳。

  • 中文直译：都说了……！
  • 例句：行かないって！ もう 決めたんだ。（都说了我不去了！我已经决定好了。）

「っこ」

专门接在动词连用形（词干）后面的口语接尾词。核心作用只有两个：把动词“名词化”，以及为句子注入“口语化、亲近感、游戏感或强烈语气”。

  1. 构成名次：表示“做某事的游戏 / 互相做的动作”
    • 将动词变成一个轻松、具象的名词，常用于儿童语言、日常口语或游戏场景。
    • 接续：动词连用形（词干） + っこ
    • 抱く（抱） → 抱き → 抱っこ（だっこ）：抱抱
    • 駆ける（跑） → 駆け → 駆けっこ（かけっこ）：赛跑
    • 睨む（瞪） → 睨み → 睨みっこ（にらみっこ）：瞪眼比赛（看谁先笑）
    • 追う（追） → 追いかけ → 追いかけっこ：捉迷藏 / 追逐游戏
  2. 构成否定句型：「〜っこない」（绝不可能……）
    • 核心的语法考点。它与否定形容词 「ない」 强强联手，表示对某种可能性的强烈否定（带有说话人主观的断定、轻视或劝阻语气）。
    • 接续：动词连用形（词干） + っこない
    • 语法含义：“连做这个动作的影儿都没有” → 根本不可能…… / 想都别想……
    • 分からっこない（わかる → わかり）：怎么可能会懂！
    • 来っこない（くる → き）：他绝对不可能来的。
    • できっこない（できる → でき）：这种事根本做不到。
  3. 衍生口语用法：「〜っこなし」
    • 除了拼「ない」，它还能拼「なし」（表示“没有 / 禁止”）
    • 含义：约定好不许做某事 / 绝不……
    • 恨みっこなし（うらむ → うらみ）：说好了，事后谁也不许记恨谁。
    • っこなしにしよ：咱们约定好不许耍赖。

过去式 + り

“有时…有时…” 列举两个及以上的动作，暗示有其他动作。若前后动作意思对立，表示动作反复进行。

  1. 名词/な形容词词干 + だったり
  2. い形容词词干 + かったり
  3. 动词た形 + り

注意: 使用[～たり（など）する], 只列举一个代表性的例子，暗示还有其他动作。

普通形 + し

“即…又…” 列举两个或以上的原因，暗示还有其他原因的存在。

  1. 动词普通形/い形容词普通形 + し
  2. な形容词词干 + だ　+　し (应该包含所有普通形)
  3. 名词 + だ +　し (应该包含所有普通形)

~まま

必须用在“已经形成并持续留存的状态”上。底层逻辑非常单一：“保持原样 / 保持某种状态不变”。在某种状态保持不变的情况下，去进行后面的动作。

  1. 动词た形 + まま
  2. 动词ない形 + まま
  3. い形容词辞书形 + まま
  4. な形容词词干 + な + まま
  5. 名词 + の + まま
  6. 指示代词(この、その等) + まま

〜がる

本质是将“内心的主观感受/欲望”转化为“外在表现出来的言行举止”。(感受/感情形容词 + がる = 变成表示“表露该情感”的五段动词)

  1. 一类形容词（い形）,去「い」 + がる
    • 怖い → 怖がる 表现得害怕
    • 痛い → 痛がる 显得很疼/喊疼
  2. 二类形容词（な形）,词干 + がる
    • 不思議 → 不思議がる 显得不可思议/纳闷
    • 嫌い → 嫌がる 表现出讨厌/抗拒
  3. 愿望助动词「たい」,去「い」 + がる（变 〜たがる）
    • 食べたい → 食べたがる（第三人称）想吃
    • 行きたい → 行きたがる（第三人称）想去

注意：不能直接接在普通动词后面。若要表示“想做某事”，必须先变成 「〜たい」 形式，再接 「〜がる」（即 〜たがる）。

用法:

  1. 描述第三人称的情感、感觉与愿望(一类形容词（如 痛い、怖い）和愿望（〜たい）原则上只能用于第一人称。)
    • 嫌がる：犬が病院を嫌がる。（狗表现出很讨厌去医院。）
    • 〜たがる：妹は新しい服を買いたがっている。（妹妹显得很想买新衣服。）
  2. 用来形容某人性格上“总是容易表现出某种状态”或“某种体质/倾向”。
    • 寒がり / 寒がる：彼は暑がりで、私は寒がる。（他怕热，我怕冷。）
    • 怖がり：怖がる性格を治したい。（想治好容易害怕的性格。）
  3. 当用于第一人称，或者带有特定语境时，它表示故意表现出某种样子给别人看
    • 強がる：強がったあと一人泣く。（逞强之后一个人偷偷哭泣。）
    • 得意がる：テストで満点を取って得意がっている。（考了满分，得意洋洋地炫耀/卖弄。）

衍生用法:

  1. 名词化：将「〜がる」变成连用形 「〜がり」，可以直接作为名词，指代某种特定性格或体质的人:
    • 暑がり（あつがり）：怕热的人
    • 寒がり（さむがり）：怕冷的人
    • 怖がり（こわがり）：胆小鬼 / 易受惊吓的人
    • 寂しがり（さびしがり）：容易感到寂寞、黏人的人
  2. 状态持续：〜がっている（最常用的口语形态） 在实际口语和描写中，表达“当下正在表露某种情绪”时，80% 以上都会使用 「〜がっている」：
    • ❌ 子供が痛がる。（较少单独作为句尾，显得像客观规律）
    • ⭕️ 子供が痛がっている。（孩子正在喊疼/显得很疼。）

〜たら

相当于中文的“如果……”、“……之后” (前面的动作/状态“先发生/成立”，然后才触发后面的内容。)

  1. 动词,动词た形 + ら
    • 食べる → 食べた →,食べたら（如果吃了/吃完后）
    • 行く → 行った →,行ったら（如果去了/到了后）
  2. 一类形容词（い形）,去「い」 + かったら
    • 高い →,高かったら（如果贵的话）
  3. 二类形容词（な形）,词干 + だったら
    • 暇 →,暇だったら（如果空闲的话）
  4. 名词,名词 + だったら
    • 雨 →,雨だったら（如果是下雨的话）
  5. 否定（〜ない）,去「い」 + かったら,
    • 行かない →,行かなかったら（如果不去的话）

用法:

  1. 纯粹假设（如果……）
    • 表示对未发生、不确定事情的假设。后面可以接请求、意志、命令、提议。
    • 雨が降ったら、行きません。（如果下雨，我就不去了。）
    • 安かったら、買ってください。（如果便宜的话，请买下来。）［接请求］
    • 時間があったら、映画を見に行こう。（如果有时间，咱们去看电影吧。）［接提议］
  2. 顺序接续 / 完成后（……之后、做完……就）
    • 表示前面动作完成后，紧接着做后面的事（强调时间上的先后顺序）。
    • 家に帰ったら、すぐお風呂に入ります。（回到家之后，马上洗澡。）
    • 仕事が終わったら、連絡してください。（工作结束之后，请联系我。）
  3. 意外发现（做完某事后，发现/注意到……）
    • 用于描述过去发生的事，前面做了一个动作，结果意外地发现了后面的事实。后面的句子通常是过去式（た形）。
    • 窓を開けたら、雪が降っていた。（一打开窗户，发现外面下雪了。）
    • 家に帰ったら、手紙が届いていた。（回到家一看，信已经送到了。）
  4. 虚拟假设（要是……就好了 / 与事实相反）
    • 对过去未发生的事情进行追悔，或者对不可能发生的事进行假设。
    • もっと勉強していたら、合格できたのに。（要是当时多学学，就能考上了。）
    • 自分が鳥だったら、君のところへ飞んでいくのに。（我如果是只鸟，就飞到你身边了。）

常用搭配： もし ＋ 〜たら：常用于增强“假设”的语气（例：もし暇だったら…… / 如果有空的话……）。

(前后两件事纯粹是并行发生、或者没有先后顺序的客观真理（例如“一加一等于二”不宜用たら）。除此之外，口语里想表达条件/假设时，用「たら」基本不会出错。)

「〜なら」（口语里的「〜のなら / 〜んなら」）

相当于中文的“要是……的话”、“如果是……的话”(根据对方的话/现有的情境，做出判断、建议或评价)

  1. 名词,直接接 なら,
    • 明日 →,明日なら（要是明天的句）
  2. 二类形容词（な形）,词干（不加な） + なら,
    • 暇 →,暇なら（要是有空的话）
  3. 一类形容词（い形）,原形 + なら,
    • 便宜 →,安（やす）いなら（要是便宜的话）
  4. 动词,原形/た形 + なら,
    • 行く →,行くなら（要是你去的话）

💡 口语：在动词、形容词后面，经常会加一个 「の / ん」 变成 「〜のなら / 〜んなら」，语气会更偏向“既然是这种情况的话……”（例如：行くのなら / 安いんなら）。

用法

  1. 承接话题，给出建议/命令/意志（最核心用法！）
    • 根据对方刚刚说的话或眼前的状况，引出自己的看法、建议或打算。
    • A：明日、京都に行きます。（我明天去京都。）
    • B：京都に行くなら、清水寺がおすすめですよ。（要是去京都的话，推荐清水寺哦。）
    • 安いなら、買います。（要是便宜的话，我就买。）
    • 嫌（いや）なら、断（ことわ）ってもいいよ。（要是讨厌/不愿意的话，拒绝掉也可以哦。）
  2. 把某个特定范围拿出来单独讨论，相当于“针对……来说的话”。
    • A：日本語が話せますか。（你会说日语吗？）
    • B：ひらがななら、読めます。（如果是平假名的话，我能读。）
    • コーヒーはありませんが、お茶ならあります。（没有咖啡，但如果是茶的话，倒是有。）
  3. 虚拟/假设条件（既然是这样的话）
    • 接在动词过去式或否定式后面，表示“既然事情已经到了这一步的话……”。
    • そこまで言（い）うなら、やってみよう。（既然你都说到这个份上了，那我就试试吧。）
    • 行かないなら、早く言ってね。（要是不去的，提早告诉我哦。）

区分なら VS たら:

  1. 「たら」：前因后果。前面的动作必须先发生，才能做后面的事。
  2. 「なら」：后发先至 / 针对前提。前面的动作不一定发生，后面是针对这个前提做出的判断。
  • ⭕️ 日本に行ったら、カメラを買いたい。（去了日本之后，想买相机。 → 必须到了日本之后才买）
  • ⭕️ 日本に行くなら、カメラを買っておいたほうがいい。（如果要去日本的话，最好先买个相机。 → 还没去日本，去之前就得买）

て形 + しまう

しまう 遵循普通 I 类动词（五段动词） 的常规变形规律

  1. 口语中会将 「てしまう / でしまう」 进行缩略，分为 ちゃう 和 じゃう 两类

  2. ～ て ＋ しまう → ～ ちゃう

    • 原型：食べてしまう → 食べちゃう（吃掉）
    • 过去式：变 ～ちゃった（例：食べちゃった / 吃掉了）
    • 礼貌形：变 ～ちゃいます（例：食べちゃいます）

  3. ～ で ＋ しまう → ～ じゃう（维持浊音）

    • 原型：底で（飲んで）しまう → 飲んじゃう（喝光）
    • 过去式：变 ～じゃった（例：飲んじゃった / 喝光了）
    • 礼貌形：变 ～じゃいます（例：飲んじゃいます）

じゃ 和 ちゃ

  1. 名词 + で + は → 名词 + じゃ
  2. 动词 て形（带浊音的 で） + は → 动词 + じゃ
  3. 格助词 で（表示方式/地点） + は → 助词 + じゃ
  4. 一类形容词的连用形是 くて（这也是个清音 て）。当它接 は 时，くて + は → くちゃ
    • 痛くては困る → 痛くちゃ困る（要是疼的话可就麻烦了）
  5. 拟声拟态词 / 接续词 + て (有些副词或接续词本身自带 て，接 は 时也会变 ちゃ)
    • だって（接续词：但是/因为） + は → 嘴里连读有时也会带出 ちゃ 的口音。
  6. 动词（清音て形）行っちゃダメ（不能去）

规律: 所有ては → ちゃ， では →じゃ

「じゃ」的包容性极广（名词、形容动词、动词、助词全涵盖）；而「ちゃ」基本被动词承包，但也包含了一类形容词（くては）。

は

  1. 提示主题（最基础）
    • 私 は 学生です。（关于我，是个学生。）
  2. 把两个事物进行对比，或者在否定句中强调否定对象。
    • 例句（对比）： お茶 は 飲むが、コーヒー は 飲まない。（茶我是喝的，但咖啡我不喝。）
    • 例句（否定强调）： そこには行かない（不去那里） → そこへは行かない（那里我才不去呢/强调绝对不去）。
  3. 挂在动词 て形 后面，把“某个动作/行为”提出来作为假设的前提条件，相当于“要是做了……的话”
    • ここに入ってはいけない → 入っちゃダメ（不能进去）。
    • （口语音变为 ～ちゃ / ～じゃ）
    • 好きになっては（ダメ） → 好きになっちゃ…（要是喜欢上的话可不行/要是喜欢上了……）。
  4. 可以叠挂在 に、で、から、まで、へ 等格助词后面，用来强调地点、时间、范围或起点。
    • には： 部屋には誰もいない。（房间里呀，一个人也没有。）
    • では： 東京では桜が咲いている。（在东京那边，樱花已经开了。）
    • からは / 破れからは： 10時からは会議です。（10点起开始开会。）
  5. 挂在数量词后面，表示“至少/起码”或者强调数量之多。
    • 10人は来るでしょう。（至少会有10个人来吧。）
    • 1時間は待った。（足足等了一个小时。）

「々」

「々」本质上就是一个用来省事的缩写符号！

  1. 時々 原本就是 時時
  2. 日々 原本就是 日日
  3. 人々 原本就是 人人
  4. 色々 原本就是 色色
