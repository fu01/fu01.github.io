使用conky监控硬件

conky Github

安装

sudo apt update && sudo apt install conky-all conky-all

包含了所有编译好的扩展模块（比如对更高阶图像、Cairo 绘图、网络协议以及我们前面一直在调用的 hwmon 硬件监控的完整支持）

运行

conky -c 配置文件路径

配置

默认的配置文件位置是 ~/.config/conky/conky.conf 或 sysconfdir/conky/conky.conf。在大多数系统中，sysconfdir 是 /etc，您可以在 /etc/conky/conky.conf 中找到示例配置文件。

命令conky -C将输出一个基本配置
