各类数学符号、算式以及常见表达式的念法

基本四则运算

  1. 加法（＋）：たす 或 プラス
    • 1 + 2 = 3
    • 念法：いち たす に は さん（或 いち プラス に は さん）
  2. 减法（－）：ひく 或 マイナス
    • 5 − 3 = 2
    • 念法：ご ひく さん は に
  3. 乘法（×）：かける 或 タイムズ
    • 4 × 3 = 12
    • 念法：よん かける さん は じゅうに
  4. 除法（÷）：わる
    • 8 ÷ 2 = 4
    • 念法：はち わる に は よん

等号与不等号

  1. 等于（＝）：は 或 イコール
    • 在算式中，最常用简单的 は（ha）来表示“等于”。
    • a = b 念作：エー イコール ビー
  2. 不等于（≠）：イコールではない 或 ノットイコール
    • a ≠ b 念作：エー は ビー ではない
  3. 大于 / 小于（＞ / ＜）：より大きい / より小さい
    • a > b 念作：エー は ビー より大きい（或 エー 大（だい）なる ビー）
    • a < b 念作：エー は ビー より小さい
  4. 大于等于 / 小于等于（≥ / ≤）：以上（いじょう） / 以下（いか）
    • a ≥ b 念作：エー は ビー 以上
    • a ≤ b 念作：エー は ビー 以下

分数、小数与乘方

  1. 分数（$\frac{b}{a}$）：分母 分の 分子（ぶんぼ ぶんの ぶんし）
    • 注意顺序与中文相反，先念分母再念分子。
    • $\frac{2}{3}$（三分之二）念作：さん ぶんの に
  2. 小数（.）：点（てん）
    • 3.14 念作：さん てん いち よん
  3. 乘方 / 次方（xn）：乗（じょう）
    • x2（平方）念作：エックス の にじょう（或 二乗）
    • x3（立方）念作：エックス の さんじょう
    • xn（n次方）念作：エックス の エヌじょう
  4. 根号（$\sqrt{x}$）：ルート
    • $\sqrt{2}$ 念作：ルート に
    • $\sqrt{x}$ 念作：ルート エックス

括号

  1. 小括号 (  )：かっこ
    • (a + b) × c 念作：かっこ エー たす ビー かっこじるし かける シー（闭合括号常用 かっこじる / かっこ閉じる）
  2. 中括号 [  ]：ちゅうかっこ
  3. 大括号 {  }：だいかっこ（注：在部分场合，日语对中大括号的称呼顺序与中文习惯相反，也有人将 {} 称作大かっこ）。

例句

  1. 何よりふるまいに
    • 核心是ふるまい， 何より让除了ふるまい其余都是次要的。
  2. ただひとり
    • 使用ただ强调ひとり
  3. 心だけ
    • だけ作用是排除其他，单独指向心
  4. 愚鈍な不道徳
    • 通过な 将两个词的习性叠加在一起(不要当作な形容词)
  5. なってる
    • なる+いる
    • て形+いる的い进行了弱化和省略

语法

  • 动词ない: ない –> ぬ（古风/书面） -> ん（口语/俗语）

    1. 特例: する –> しない –> せぬ –> せん

  • より ＝ 参照点 / 坐标锚点

  • まだ見ぬ（まだみぬ）：尚未见过的、未知的

    1. 副词将自身状态叠加到后面
    2. 相当于見ぬ在自身属性的基础上，得到了まだ的属性词条

  • A と B

    1. 关联A和B

  • A に B

    1. A 为终点或目标，B就是指向这个目标的动作或状态。

  • A なら

    1. 假设A存在

  • A まで B

    1. A条件一旦达成 B停止

  • 同じ月

    1. 要通过参照物理解同じ
    2. 参照物可以是过去的事物或现在其他事物

  • A で B

    1. B的执行建立在A存在的基础上

  • A から B

    1. A的基础上，延伸出B的内容

  • A も

    1. A具备前面提及事物属性

  • ～っこない

    1. 接续方式：动词 ます形 去掉 ます ＋ っこない
    2. 强烈的“绝对不可能”否定，表达说话人主观上坚信某事绝对不会发生、绝对做不到

  • ます形 5分支

    1. 基本形（原型）：行く ➔ 行きます
    2. 可能态（能……）：行ける ➔ 行けます
    3. 被动态（被……）：行かれる ➔ 行かれます
    4. 使役态（让……）：行かせる ➔ 行かせます
    5. 使役被动态（被迫……）：行かせられる ➔ 行かせられます

  • A + ばっかり(或～ばかり)

    1. A 可以是**单词、短语或句子
    2. 只有 A / 全是 A / 光顾着 A（被 A 挤满，没有别的）
    3. 特例：唯独接动词过去式（た形）时，意思会发生偏转，变成 “动作刚发生”（比如 食べたばっかり 并不是“只有吃”，而是“才刚吃完”）

  • 动词 て形 ＋ しまう

    1. 只能接 て形 后
    2. ～てしまう 口语 ～ちゃう / ～じゃう
    3. 表示前面的动作状态: “彻底做完 / 搞定 / 状态不可逆”
    4. 功能1: 负面情绪：后悔、遗憾、糟糕（无可挽回）
    5. 功能2：正面/爽快情绪：彻底搞定、爽快完成、爽快痛快
    6. 根据しまう 前面的内容去理解是那种功能
    7. 注意：尾音う 会习惯性省略不念

  • 动词 て形 ＋ 动词(汉字书写)

    1. 两个动作是平等的，A 是前一个动作，B 是后一个动作。
    2. 例子: 本を買って 読む。 （买了书，然后读。）

  • 动词 て形 ＋ 动词(假名书写)

    1. 辅助前面的动词て形，附属于前面 (语法插件 / 语气、状态、趋势)
    2. 例子: 本を買って みる。（买来读读看 / 尝试。）

  • 动词 て形 ＋ 【形容词 / 名词 / 句尾助词】

    1. 字面意思理解

  • て形 分为两种

    1. 清音版: 动词て形和イ形容词て形
    2. 浊音版: 名词/代词/数词/量词 + で和ナ形容词（形容动词） + で (只要で是后加的 都算 例如: ないで )

  • て形 口语

    1. ては => ちゃ
    2. では => じゃ

  • て形 6分支

    1. 辞书形（原型）：書く ➔ 書いて
    2. 可能态（能/会）：書ける ➔ 書けて
    3. 被动态（被……）：書かれる ➔ 書かれて
    4. 使役态（让/使）：書かせる ➔ 書かせて
    5. 使役被动态（被迫）：書かされて（五段）/ 食べさせられて（一段）
    6. イ形容词: 高い ➔ 高くて

  • ～たい

    1. 动词ます形（去掉ます） + たい （只能接动词后）
    2. 表达主观愿望
    3. 词性改变为 イ形容词

  • ～にくい

    1. 动词ます形（去掉ます） + にくい （只能接动词后）
    2. 做起来【困难/复杂/难……】
    3. 词性改变为 イ形容词

  • ～やすい

    1. 动词ます形（去掉ます） + やすい （只能接动词后）
    2. 做起来【简单/容易/好……】
    3. 词性改变为 イ形容词

  • イ形容词 5分支

    1. 常规 イ形容词
    2. 动词ない形
    3. 动词+たい
    4. 动词+にくい
    5. 动词+やすい

  • A さえ B

    1. 插入 客观陈述的句子中，进行极端锚定与逻辑加压
    2. 功能1: 否定/无能为力, 把A锚定为最简单、最基础、最底线的事情。B否定了A，暗示比A更复杂的事情更不可能做到。
    3. 功能2: 条件假定, 把A锚定为唯一关键要素 / 最低条件。只要A满足了，就能实现B。其他次要条件全部可以忽略。

  • 简体形式

    1. 动词：原型（辞书形）、ない形、た形、なかった形
    2. い形容词: 原型, い(词尾)变かった, い(词尾)变く 接ない, [い(词尾)变く 接なかった
    3. な形容词和名词: +だ, +だった, +ではない, +ではなかった

  • 名词 5 分支

    1. 动词的 ます形 的词干
    2. 动词的 简体原形 + こと / の
    3. い-形容词 词尾 い 变 さ / み
      • さ 客观可测量的程度/数值
      • み 主观体会到的状态/情感/滋味(有些词不具备此条件不能变み)
    4. な-形容词 + さ
    5. 任何简体句子末尾加上 の、こと 或 もの

  • 自他动词

    1. 自动词(用～が): 自发变化 / 自身移动 / 结果呈现
    2. 他动词(用～を): 改变外物 / 操作自身器官 / 意志与感知投向外物

句子构成

  • 名词和动词
    1. 意思理解: 100% 从左向右单向推进，绝对不倒装回看。
    2. 组合形式: (名词/动词) + (名词/动词) + (名词/动词)… 类推下去
    3. 不能出现名词后面是名词 或 动词后面是动词的情况。
    4. ます形 て形 命令形 意志态以外的其它动词形式 适用以上规则
